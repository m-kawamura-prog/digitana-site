利用規約

本規約は、株式会社 京都事務代行サービス（以下「当社」）が提供するAndroidアプリ「デジたな」（以下「本アプリ」）の利用条件を定めるものです。

1. 本アプリの利用

本アプリは蔵書の登録・整理、本棚画像の解析、書籍検索、読書傾向分析等の機能を提供します。利用者は本規約、関係法令およびGoogle Play等の適用される利用条件に従って本アプリを利用してください。未成年者は必要に応じて法定代理人の同意を得てください。

2. 有料機能

本棚画像の解析回数は、Google Playを通じて購入できます。現行の商品は10棚分の買い切り型で、自動更新はありません。購入価格は購入画面に表示されます。決済・購入確認後に解析回数が付与されます。

購入済みの解析回数を別端末に引き継ぐ場合は、事前にアプリ内で引継ぎコードを保存し、所定の操作を行ってください。蔵書データは別途CSVでバックアップしてください。払い戻しは下記の特定商取引法に基づく表記に従います。

3. 禁止事項

  • 法令に違反する行為、第三者の権利を侵害する行為
  • 不正な購入、解析回数の不正取得、認証・利用制限の回避
  • 本アプリや外部サービスの運営を妨げる行為

4. AI解析・書誌情報

AIの解析結果、書誌情報、書影、おすすめ等には誤りや欠落が含まれる場合があります。登録・購入等の判断に際しては利用者自身で内容をご確認ください。外部の書籍購入先での契約は当該販売事業者との間で成立します。

5. データ・知的財産権

利用者が保有する蔵書データ等の権利は利用者または正当な権利者に帰属します。本アプリのプログラム、名称、デザイン等の権利は当社または正当な権利者に帰属します。利用者情報の取扱いは下記のプライバシーポリシーに従います。

端末故障、アプリ削除等に備え、必要な蔵書データは利用者自身でバックアップしてください。

6. サービスの変更・停止

7. 責任

プライバシーポリシー

株式会社 京都事務代行サービス（以下「本アプリ運営者」）は、Androidアプリ「デジたな」（以下「本アプリ」）における利用者情報を以下のとおり取り扱います。

制定日：2026年9月28日

1. 基本方針

本アプリは、メールアドレスやパスワード等のアカウント登録を必須とせず、蔵書リスト等の主要な利用者データを原則として端末内に保存します。 一方、本棚画像のAI解析、書誌情報の取得、広告表示、購入済み解析回数の管理など、機能の提供に必要な場合に限り外部サービスと通信します。

2. 本アプリが取り扱う情報

2-1. 蔵書・本棚に関する情報

登録した書籍、ISBN、タイトル、著者、出版社、本棚・保管場所、読みたい本、タグ等の情報は、 主として利用者の端末内に保存されます。本アプリ独自のユーザーアカウント用サーバーへ蔵書リストを保存する仕組みは設けていません。

2-2. 本棚画像

利用者が本棚画像のAI解析機能を使用した場合、解析に必要な画像データおよび指示情報を Firebase AI Logicを通じてGoogleの生成AIサービスへ送信します。 本アプリ運営者が独自に運用するサーバーへ本棚画像をアップロードして保管する仕組みは設けていません。 送信先サービスにおける情報の取扱いについては、Googleの規約およびプライバシーポリシーが適用されます。

2-3. 読書傾向・おすすめ機能

読書傾向分析やおすすめ機能を利用した場合、対象となる蔵書の書名、著者、出版社、出版日、シリーズ名、タグ、 書籍説明等、および利用者が入力した自由記述の読書嗜好を、Firebase AI Logicを通じてGoogleの生成AIサービスへ 送信する場合があります。これらは読書傾向の分析、候補生成、候補順位付け等に利用します。

2-4. 書誌情報の検索

ISBN、書名、著者名、出版社名等を当社の書誌検索サーバーへ送信し、国立国会図書館のJAPAN/MARCを基にした書誌データベースで検索します。書影・紹介文の補完や新刊・おすすめの候補取得にはGoogle Books、openBD、楽天ブックス等を利用します。共有データベースにはISBNに対応する書誌情報・書影URL・紹介文等を保存しますが、利用者ごとの蔵書リストを保存するためのものではありません。

2-5. 広告に関する情報

本アプリではGoogle AdMobを利用します。広告配信のため、端末情報、広告識別子、 おおよその位置情報、広告への操作情報等がGoogleにより取り扱われる場合があります。 実際に利用される情報は、端末設定、地域、同意状況、広告設定等によって異なります。

欧州経済領域（EEA）、英国その他の対象地域では、Google User Messaging Platform（UMP）を利用し、 必要に応じて広告および関連データ利用についての選択肢を表示します。

2-6. アプリ内購入に関する情報

AI解析機能の利用権等をGoogle Playのアプリ内購入で購入する場合、購入処理に必要な情報をGoogle Playが取り扱います。 本アプリ運営者が独自の決済情報（クレジットカード番号等）を取得することはありません。 購入済み解析回数の残数、再インストール・機種変更時の引継ぎ、および二重付与・二重利用の防止のため、 Firebase Anonymous Authenticationが発行する匿名ID、購入処理に必要な識別情報、残り解析回数、 引継ぎコードのハッシュ等をFirebase Cloud Functions / Cloud Firestoreで保存します。

2-7. 診断情報

開発・サポート用の診断ログ機能を利用する場合、エラーや処理状況等が端末内の一時ファイルに記録されることがあります。 診断ログは利用者が明示的に保存・共有しない限り、本アプリ運営者へ自動送信されません。

3. 利用目的

  • 本棚画像から書籍候補を抽出するため
  • 書籍を特定し、書誌情報・書影を取得するため
  • 蔵書の整理、検索、読書傾向分析、オススメ等の機能を提供するため
  • 広告を表示し、本アプリの運営費を賄うため
  • 不具合の調査、品質改善および利用者サポートのため
  • 不正利用の防止およびサービス保護のため

4. 外部サービス

本アプリでは、機能に応じて以下の外部サービスを利用します。

  • Google Firebase / Firebase Authentication / Cloud Functions / Cloud Firestore / Firebase AI Logic / Gemini — 匿名IDによる購入済み解析回数の管理、AI解析、アプリ保護等
  • Google AdMob / User Messaging Platform — 広告配信、同意管理
  • Google Play Billing / Google Play Developer API — アプリ内購入、購入状態の検証
  • Google Books — 書誌情報・書影等の取得
  • openBD — 書誌情報・書影等の取得
  • 当社の書誌検索・共有データベース（ロリポップ！） — JAPAN/MARCを用いた書誌検索・共有書誌情報の保存
  • 楽天ブックス・楽天ウェブサービス — 書誌情報・書影の取得、新刊・おすすめの候補取得、書籍購入ページへのリンク（アフィリエイトリンクを含む場合があります）

各外部サービスでの情報の取扱いは、それぞれのサービス提供者の規約・プライバシーポリシーに従います。

5. 第三者提供

本アプリ運営者は、法令に基づく場合を除き、利用者から取得した情報を独自に第三者へ販売しません。 ただし、前項の外部サービスを利用するために必要な情報は、機能の実行に伴って各サービス提供者へ送信されます。

6. データの保存と削除

蔵書等の主要データは端末内に保存されます。アプリ内の削除機能、Androidのアプリデータ削除、 または本アプリのアンインストールにより、端末内のデータを削除できます。 CSVとして利用者自身が書き出したバックアップは、利用者が選択した保存先に残ります。 購入済み解析回数に関するサーバーデータは、再インストール・機種変更時の引継ぎのため、 アンインストールだけでは削除されません。削除を希望する場合はサポート窓口へお問い合わせください。 削除した購入済み残数は復元できません。

7. セキュリティ

本アプリは、Firebase App Check等を用いて不正なアクセスの抑制に努めます。 ただし、インターネット通信または電子的保存について絶対的な安全性を保証するものではありません。

8. 子どもの利用

本アプリは、子どもを特に対象として設計されたサービスではありません。 Google Playにおける対象年齢等の設定は、公開時のアプリ内容およびポリシーに従って行います。

9. 本ポリシーの変更

機能追加、利用する外部サービスの変更、法令・ポリシーの変更等に応じて、本ポリシーを改定することがあります。 重要な変更がある場合は、本ページまたはアプリ内で適切な方法により案内します。

10. お問い合わせ

本アプリおよび本ポリシーに関するお問い合わせは、 support@kyoto-service.com までご連絡ください。
